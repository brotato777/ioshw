# 今天怎麼去？— 隨機移動方式 App

輸入想去的地方，按下「抽取」，App 會隨機推薦一種移動方式和一個（可能非常誇張的）預估時間。
從走路、搭公車，到月球漫步、騎隱形駿馬，甚至是傳說級的「搭乘銀色殭屍吉娃娃」。

![素材總覽](docs/preview.png)

## 功能

- 輸入目的地，點「抽取」按鈕隨機抽一種移動方式，卡片會翻轉一圈揭曉結果
- 以圖文呈現答案，每次顯示四種資訊：
  1. **移動方式**：卡片圖片＋名稱（例如「推薦你騎掃把飛行去學校」）
  2. **預估時間**：從普朗克時間到一兆年隨機產生，並用中文大數單位顯示（例如「3.2 億年」「1.5 垓個普朗克時間」）
  3. **稀有度**：基礎／搞怪／傳說
  4. **玩法說明**：這種移動方式實際要怎麼做
- 純隨機，不需要取得使用者位置

## 資料設計

| 型別 | 說明 |
| --- | --- |
| `Move` | 一種移動方式：id、名稱、稀有度、權重、說明、圖片名稱、主題色 |
| `Rarity` | 稀有度列舉：`common`（基礎）、`rare`（搞怪）、`legendary`（傳說） |
| `DrawResult` | 一次抽取結果：目的地、抽到的 `Move`、預估秒數 |
| `TravelTime` | 產生隨機時間與格式化成中文字串 |

- 13 筆移動方式資料存在 `Move.all` 陣列中
- 依權重抽取（總和 100，等於百分比），傳說級殭屍吉娃娃機率 10%
- 預估時間有 40% 機率落在「正常」的 1 分鐘～3 小時，其餘 60% 在普朗克時間（5.39×10⁻⁴⁴ 秒）到一兆年之間以對數均勻分佈

## 專案結構

```
ioshw4/
├── MyApp.swift          # App 進入點
├── ContentView.swift    # 主畫面與結果顯示
├── Move.swift           # 資料型別、資料陣列、隨機與時間格式化
└── Assets.xcassets/
    └── Moves/           # 13 張移動方式卡片 + 卡背
```

## 執行

用 Xcode 開啟 `ioshw4.xcodeproj`，選擇 iPhone 模擬器後按 ⌘R 執行。
